# Wedding Programme

React + Vite.

```
npm install
npm run dev      # local preview
npm run build    # production build in /dist
```

Edit content in `src/data.js` (ministers, order of service, hymns, bridal train, reception, Bible reading via `BIBLE`). Replace the photo at `src/assets/couple.jpg`. Deploy the `dist` folder (or connect the repo) on Vercel.
